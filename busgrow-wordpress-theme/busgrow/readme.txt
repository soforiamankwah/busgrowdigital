Custom WordPress theme for Busgrow Digital Agency.

== INSTALL ==
1. In WordPress go to Appearance > Themes > Add New > Upload Theme.
2. Choose busgrow-wordpress-theme.zip, click Install Now, then Activate.
3. On activation the theme automatically creates the pages (Home, About, Services, Let's Grow, Blog, Contact),
   sets the homepage and blog page, builds the main menu and adds six starter blog articles with their images.

== EDITING ==
* Pages: Pages > open a page > edit. Each section is a block (Custom HTML). Click a block and edit the text,
  or use the block toolbar to switch between Preview and HTML.
* Blog articles: Posts > All Posts. They are normal WordPress posts (title, text, category, featured image).
* Menus: Appearance > Menus.
* Phone, WhatsApp, emails, address, hours, social links and the "Book a Call" link:
  Appearance > Customize > Busgrow Settings. These appear in the header, footer and Contact page.
* Contact form: messages are emailed to the main email set in Busgrow Settings.
* Page descriptions for search engines: the Excerpt box on each page.

== NOTES ==
* Site Title: set it under Settings > General.
* If you install an SEO plugin (Yoast, Rank Math), it takes over the page titles and descriptions.
* Use a normal WordPress site (or a multisite super admin). Page sections are saved as Custom HTML blocks, which WordPress only allows for users with the unfiltered_html capability (Administrators on a standard site).
* If emails from the contact form do not arrive, install an SMTP plugin (for example WP Mail SMTP).
